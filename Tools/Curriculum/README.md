# Curriculum tooling

- `Generators/`: script dựng roadmap và material.
- `Specifications/`: đặc tả nguồn của generator.
- `Maps/`: ánh xạ phase/module.
- `Snapshots/`: bản draft lịch sử.
- `Manifests/`: phê duyệt và bằng chứng provenance.
- `Validators/`: kiểm tra cấu trúc hiện hành.

Các generator được chuyển nguyên trạng từ `.data-2026`. Chúng chưa được sửa đường dẫn cho cấu
trúc mới và không được chạy cho tới khi hoàn tất migration toolchain.
