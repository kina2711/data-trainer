# OpenLineage — Overview

## Phạm vi đã đọc

Nguồn dùng để định vị technical lineage: metadata về datasets, jobs và runs; pipeline components phát sự kiện qua standard API để phân tích cách dữ liệu được tạo và sử dụng. Giáo trình phân biệt lineage kỹ thuật này với requirements traceability nối quyết định, câu hỏi và metric.

## Locator đã dùng

- Dòng 4–16: mục tiêu project, datasets/jobs/runs, impact analysis và API thu thập lineage events.
- Job Lineage facet: declared hoặc observed job inputs/outputs và job-to-job relationships.

## Giới hạn

OpenLineage không tự biết business decision, metric contract hoặc justification. Nối technical nodes với decision traceability cần stable IDs và metadata bổ sung của tổ chức.
