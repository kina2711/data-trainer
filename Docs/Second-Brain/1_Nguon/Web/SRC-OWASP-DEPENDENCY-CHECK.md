# OWASP Dependency-Check — hồ sơ nguồn

## Phạm vi sử dụng

Trang dự án được dùng cho định nghĩa Software Composition Analysis: nhận diện dependency rồi đối chiếu với lỗ hổng đã công bố. Kết quả phụ thuộc khả năng nhận diện component và dữ liệu vulnerability; một finding không tự chứng minh code path bị khai thác được.
