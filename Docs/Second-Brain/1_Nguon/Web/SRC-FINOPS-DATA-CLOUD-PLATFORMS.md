# FinOps for Data Cloud Platforms — hồ sơ nguồn

## Phạm vi đã đọc

- Correlation giữa billing data với query/job history, execution logs và workload identifiers.
- Consumption currencies như credits, DBUs và slots; compute utilization, storage, transfer, concurrency và autoscaling.
- TCO gồm compute, storage/retention, transfer/egress, orchestration, catalog, lineage, governance, licensing/support.
- Unit metrics như cost per query, pipeline, dashboard, model run hoặc TB processed; baseline và variable consumption.

## Giới hạn

Framework không cung cấp một bảng giá hay công thức vendor duy nhất. Allocation shared cost là policy cần owner; unit cost kỹ thuật không tự chứng minh business value.
