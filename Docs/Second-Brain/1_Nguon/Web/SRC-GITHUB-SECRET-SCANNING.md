# GitHub Secret scanning — hồ sơ nguồn

## Phạm vi sử dụng

Tài liệu được dùng cho phạm vi quét secret trên toàn bộ Git history và nguyên tắc xử lý credential đã lộ: thu hồi hoặc rotate trước, sau đó mới cân nhắc dọn lịch sử. Tính năng và quyền truy cập phụ thuộc gói GitHub; note không giả định mọi kho riêng tư đều có cùng khả năng.
