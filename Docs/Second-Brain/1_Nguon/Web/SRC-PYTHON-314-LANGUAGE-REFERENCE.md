# Python 3.14 Language Reference — hồ sơ nguồn

## Phạm vi đã đọc

- Data model: object identity, type, value, mutability, container references, resource finalization và implementation-specific qualifiers.
- Iterator, generator, coroutine và asynchronous-generator object models; `yield`, `return` và termination semantics.
- Exception propagation, `try`/`finally`, `with` protocol và explicit resource cleanup.
- Truy cập ngày 2026-10-02 trên tài liệu Python 3.14.8.

## Giới hạn

- Những đoạn được đánh dấu CPython implementation detail không được trình bày như guarantee của mọi Python implementation.
- Tài liệu ngôn ngữ mô tả semantics; chi phí hiệu năng phải được đo trên interpreter, workload và version cụ thể.
