# BigQuery pricing and slots — hồ sơ nguồn

## Phạm vi đã đọc

- Hai mô hình compute: on-demand theo bytes processed và capacity theo slot resources over time.
- Slot là virtual compute unit; slot use phụ thuộc data processed, query complexity và available capacity.
- Các nhóm charge tách biệt gồm analysis/compute, storage và một số data-transfer hoặc API paths.

## Giới hạn

Giá, minimum billing, miễn phí, editions, commitments và data-transfer rules thay đổi theo thời gian, region và contract. Knowledge note chỉ lưu đại số và metric contract; rate card phải snapshot tại thời điểm quyết định.
