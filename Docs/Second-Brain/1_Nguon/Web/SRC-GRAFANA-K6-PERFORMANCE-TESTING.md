# Grafana k6 — hồ sơ nguồn performance testing

## Phạm vi đã đọc

Đã đọc hướng dẫn automated performance testing và load testing websites. Taxonomy được dùng gồm smoke, average-load, stress, spike và soak. Nguồn yêu cầu workload đủ giống hành vi thật, môi trường phù hợp, threshold tự động và kết quả lặp lại được; đồng thời cảnh báo không tạo tải lên hệ thống bên thứ ba khi chưa được phép.
